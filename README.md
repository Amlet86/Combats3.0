# Combats 3.0

Бот для браузерной онлайн-игры [Бойцовский клуб](https://dreamscity.combats.com/) (DreamsCity, combats.com).
Входит в игру под вашим персонажем и сам проводит бои: PvP в хаотичных поединках или PvE в подземелье.
Работает через настоящий браузер Chrome, которым управляет [Selenide](https://selenide.org/).

## Возможности

- **PvP** — подаёт заявку на хаотичный бой или вступает в чужую с ближайшим стартом, проводит бой,
  после боя ждёт восстановления HP и идёт в следующий.
- **PvE** — ходит по подземелью по маршруту из папки `maps/` и сражается с монстрами.
- **Бой** — на каждом ходу выбирает приём, случайную зону удара и зону блока; после боя нажимает «Вернуться».
- **Время окончания** — бот заканчивает игру в заданное время (начатый бой доигрывает).
- **Окно статуса** — показывает, чем сейчас занят бот, и останавливает игру кнопкой **Stop**.
- **Устойчивость** — после сбоя (лаг, всплывающее окно) перезагружает страницу и продолжает;
  останавливается только после 3 ошибок подряд или при неудачном входе.
- **Без окна** — браузер можно запустить в фоне (headless).

## Требования

- JDK 21
- Google Chrome. ChromeDriver под установленную версию Chrome скачивается автоматически (Selenium Manager)
- Maven 3.9+ (можно встроенный в IntelliJ IDEA)

## Сборка и запуск

```bash
mvn clean package
```

Соберётся `target/Combats-3.0.0.jar` со всеми зависимостями. Запуск:

```bash
java -jar target/Combats-3.0.0.jar
```

или скриптом `./start` из корня проекта. Из IntelliJ IDEA — класс `com.combats.Start`.

## Как пользоваться

1. Заполните форму:

   | Поле | Значение |
   |---|---|
   | Login, Password | логин и пароль персонажа |
   | PvP / Dungeon | режим игры |
   | Pet | использовать питомца в бою |
   | Browser off | запустить браузер без окна |
   | End time | время окончания игры; `0 : 00` — без ограничения |
   | Telegram | имя и токен Telegram-бота (интеграция пока не подключена, см. ниже) |

2. Нажмите **Start**. Форма закроется, откроется браузер и окно статуса.
3. Чтобы остановить бота досрочно, нажмите **Stop** в окне статуса — браузер закроется.
   После окончания игры в окне будет причина остановки.

Для PvE персонаж должен уже находиться в подземелье: дорогу туда бот не ищет.

### Где хранятся логин и пароль

После успешного входа логин, пароль и данные Telegram сохраняются в `~/.combats/user-data.txt`
(в Windows — `C:\Users\<пользователь>\.combats\`), чтобы при следующем запуске форма заполнилась сама.
Файл лежит вне проекта и не попадает ни в git, ни в jar. Пароль хранится в открытом виде, поэтому
не используйте этот пароль на других сайтах.

### Логи

Лог пишется в консоль: время, поток, класс и сообщение. Каждое действие из окна статуса тоже попадает в лог.
При ошибке Selenide сохраняет скриншот страницы в папку `fails/`.

## Устройство проекта

```
src/main/java/com/combats
├── Start.java          точка входа
├── fe/                 Swing: форма настроек и окно статуса
├── be/                 логика игры: настройка браузера, вход, игровой цикл с повторами
├── pages/              Page Object для страниц игры: вход, город, заявки, бой, подземелье
├── utils/              настройки игры, время игры, остановка, файл пользователя, маршрут
├── exception/          сигналы «время вышло» и «остановлено пользователем»
└── telegram/           Telegram-бот (сейчас не подключён)
```

- Игра идёт в отдельном потоке `game`, интерфейс не блокируется.
- Экран боя игра рисует в основном документе, а город и заявки — в iframe;
  Page Object переключаются между ними сами.
- [`docs/game-pages.md`](docs/game-pages.md) — справочник страниц игры: фреймы, кнопки, состояния экрана боя
  и рабочие локаторы. Если сайт поменяет вёрстку, начинать стоит с него.
- [`docs/tools/`](docs/tools) — регистратор для снятия снимков страниц игры и скрипт их разбора.

## Тесты

```bash
mvn test
```

JUnit 5: время окончания игры, разбор HP со страницы, остановка игры кнопкой Stop.
Взаимодействие с самой игрой автотестами не покрыто — для него нужен вход под реальным персонажем.

## Ограничения

- **Telegram-интеграция не работает:** бот не запускается из формы, а библиотека `telegrambots 4.4` устарела.
- Если в момент остановки (по времени или кнопкой Stop) уже подана заявка на хаотичный бой, она остаётся в игре.
- В PvP бот ищет кнопку «Поединки», которая есть не во всех комнатах города (есть в Зале воинов и Таверне).
- Выбор приёмов простой: всегда первый доступный.
- Автоматизация игры может противоречить правилам игры. Используйте на свой риск.
